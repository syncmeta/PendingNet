# PendingNet 0.3.46（348）

## 链接归属

- 管理应用与 VPS 菜单签发前选择已有用户，或明确新建命名用户。
- PendingNet 配对链接复用所选用户；配对设备、VLESS 凭据及流量均归入该身份，重复签发不再隐式增加用户。
- 非交互式 `links`、`pair create` 必须提供 `--user`；API 签发必须提供 `user_id`。
- 已撤销用户不能签发，普通用户不能借管理链接角色升级权限。已有节点与配对设备继续有效。
- 管理应用需要与支持用户选择的服务端配合使用。

## macOS 打包

- 修复 Debug 动态库与主程序签名团队不同导致的启动终止。
- 嵌套应用动态库先签名，再签外层应用；额外检查动态库签名团队。
- 正式 Release 禁用 Debug dylib，并检查包内依赖。

## 流量诊断工具

仓库附带可选的服务流量采集与连接/TLS 元数据监测脚本及 systemd 单元。它们不由升级脚本自动部署。原始来源地址保存在服务器私有目录，默认报告使用匿名来源；不保存抓包文件或通信正文。

## 内核与验证

沿用已验证的 Xray v26.3.27、Hysteria2 v2.13.0 和锁定的 sing-box 源码。此版不重新选择上游最新内核。

完整 Go 测试通过；Swift 核心共 349 项测试，1 项跳过、零失败。macOS 发布物执行 universal、Developer ID 签名、嵌套签名团队、依赖、公证及解包校验。正常窗口启动和旧版更新流程没有在本次重跑；构建期间保留正在运行的旧版客户端。

macOS 需要 macOS 14 或更新系统，以及已部署 PendingNet Server 的 VPS。GitHub Release 提供 macOS 客户端及 Linux amd64/arm64 服务端；iOS 仍通过 TestFlight/App Store 分发。
