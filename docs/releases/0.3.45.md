# PendingNet Server 0.3.45（347）

日期：2026-10-24（Asia/Taipei）。本次范围为 Linux 服务端；macOS 和 TestFlight 客户端沿用 [0.3.44](https://github.com/syncmeta/PendingNet/releases/tag/pendingnet/v0.3.44)。

## 更改端口

- `sudo pendingnet` 新增菜单 **15. 更改端口**，显示当前 Reality TCP 与 Hysteria2 UDP 端口，分别输入新值，留空保持，并在应用前确认。
- `sudo pendingnet ports` 查看端口；`sudo pendingnet ports --reality 8443 --hysteria2 9443` 直接更改。
- 同步更新节点资料、Xray 与 Hysteria2 配置，保留现有密钥、证书和用户凭据；支持共享与独立用户配置。
- 校验端口范围和占用，防止误用管理及流量统计端口；操作与用户配置同步、内核更新共用互斥锁。
- 应用前保留私有备份；重启失败时恢复原配置并再次尝试启动旧服务。原本停止的代理服务保持停止。

更改前先在 VPS 防火墙和云安全组放行新端口。应用会短暂中断代理连接；客户端需刷新节点配置，使用标准节点链接的客户端需重新导入更新后的链接。管理接口地址保持原值。

## 内核与发布范围

沿用 0.3.44 的 Xray 26.3.27、Hysteria2 2.13.0 与 sing-box 1.14.3 锁定输入，保留原捕获时间，仅更新清单的 PendingNet 版本绑定。Xray 兼容决定见 [0.3.44 发布记录](0.3.44.md)。本次不触发上游内核升级，也不构建或分发新的 macOS / iOS 客户端。

发布资产：Linux amd64、Linux arm64、`SHA256SUMS` 和 `upstream-lock.json`。已有 VPS 更新后，在 `sudo pendingnet` 菜单选择 15 即可使用。

## 验证范围

`go test -race ./...` 全量通过，覆盖共享及独立用户凭据保留、配置校验、端口占用与保留端口、配置版本冲突、失败回滚、菜单确认/取消/留空和命令入口。内核锁定版本绑定检查、安装器离线回归通过。具体公开资产的校验结果以发布后的核验为准。

本次发布不升级现有 VPS，也未在真实 VPS 上执行端口切换；arm64 仅交叉编译。
