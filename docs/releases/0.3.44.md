## 内核兼容决定

本版保留 Xray 26.3.27、Hysteria2 2.13.0、sing-box 1.14.3。新版 Xray 26.10.21 虽能接受生成的配置，但实际 Reality 测试失败：其 REALITY 依赖要求 ClientHello 包含 X25519MLKEM768，而当前 sing-box 会移除此字段。未将该不兼容版本部署到服务器。详细依据见 [DNS 设计记录](../design/2026-10-23-dns-policy.md)。
