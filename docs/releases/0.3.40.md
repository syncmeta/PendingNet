# PendingNet 0.3.40

This release pins client and server engines to the versions selected for this PendingNet release and adds node sharing, Traditional Chinese, and VPS deletion. The macOS and iOS build number is 341.

- Locks Xray 26.3.27, Hysteria2 2.13.0, and client sing-box 1.14.3. VPS updates use the release lock rather than whichever upstream version is newest at update time.
- Adds a recoverable VPS engine updater with checksum verification, configuration preservation, service health checks, backups, and rollback. Update existing hosts with the installer's update-only mode; there is no scheduled automatic upgrade.
- Adds Traditional Chinese on macOS and iOS, a server icon for Management, and a separate `pendingnetm://` administrator link scheme. Existing administrator links remain supported.
- Adds standard VLESS Reality / Hysteria2 sharing and new one-time PendingNet client pairing links from node details. Issuing a pairing link requires management access on that device. Standard links carry existing node credentials; they do not create a separate user.
- Adds iOS swipe-to-delete with confirmation, disconnection before deleting the selected VPS, and synchronized deletion markers to prevent stale records from reappearing. Reimporting explicitly restores a deleted node. Deleting a node does not uninstall its VPS or revoke its server-side user.
- Adds deletion of local management entries and administrator credentials, with iOS swipe-to-delete; connection nodes and VPS services remain intact.
- Removes the iOS connection status badge and the overall rule-set readiness badge, while retaining each rule-set's download state.

Hysteria2 exports use the certificate fingerprint required by its standard URI format and an additional PendingNet SPKI pin for the embedded sing-box. Servers must provide that certificate fingerprint; legacy third-party certificate-only pin links cannot be imported into the SPKI-only runtime. Unpinned imported Hysteria2 links use normal certificate validation.

Server configuration editing remains disabled. Administrator credentials remain local to the importing device. Share links only with trusted recipients. TestFlight external availability depends on Apple's beta review.
