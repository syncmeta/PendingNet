# PendingNet 0.3.39

This release delivers the safe, read-only subset of the management console.

- Adds a separate management tab, with independent local-only administrator credentials, user and first-seen IP information, scoped pairing-link issuance and revocation, and Android/Windows sing-box configuration export.
- Improves active-connection latency measurements, server protocol selection, locally assigned server names, and the connection controls.
- Adds English localization for the macOS and iOS client interfaces and common errors.
- Adds server-side per-link users and first-seen source IP recording, with compatibility for existing server state.

**Not included:** editing and restarting the live PendingNet server configuration. The production management write endpoint remains disabled (HTTP 503), and the client labels the configuration read-only until isolated validation and recovery have been tested on a disposable host. The management API requires a server built from this release; publishing the server binary does not install it on any VPS. The iOS source changes are included, but this release does not itself distribute an iOS TestFlight build.

The macOS package requires macOS 14 or later and a separately deployed PendingNet Server plus a valid pairing link. The app bundles its proxy engine; first use of system proxy or TUN may require enabling PendingNet under System Settings → General → Login Items & Extensions. Exported client configs and pairing links contain credentials: keep them private.
